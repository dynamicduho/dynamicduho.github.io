# Personal Website

Created with React

Available at [www.duho.ca](https://www.duho.ca)

## Website Features

- Cardmatching game available at [duho.ca/projects/cardmatching](https://www.duho.ca/projects/cardmatching)
  - Created for CS349 User Interfaces course assignment
  - Match all cards to win; game progressively gets more difficult as you match more cards
  - Features:
    - cards are randomly selected
    - "+" or "-" to adjust the number of cards
    - "x" to peek at all cards
    - click below a card then drag up and release on the card to peek at a single card
